# MYTHHELM brand assets

The mark is the **M crest**. The M's two peaks are the fleet of agents, the valley funnels their work to one point, and the guiding star above it is the mission.

| File | Use |
|---|---|
| `mark-on-dark.svg` / `mark-on-light.svg` | The mark alone, for dark or light backgrounds |
| `app-icon.svg` / `app-icon-512.png` | Canonical rounded-square icon: favicon (use the SVG), org and social avatar |
| `lockup-on-dark.png` / `lockup-on-light.png` | Mark + wordmark + tagline (README header) |
| `social-card.png` | 1280×640 repository social preview. GitHub doesn't pick it up automatically: upload it under Settings → General → Social preview |

## Colours

| Token | Hex | Use |
|---|---|---|
| Night | `#090f1a` | Primary background |
| Frost | `#ebeff5` | Mark and wordmark on dark |
| Ink | `#101621` | Mark and wordmark on light |
| Star (dark) | `#4ddae9` | Mission accent on dark |
| Star (light) | `#00829d` | Mission accent on light |
| Mist | `#989fab` | Secondary text on dark |

## Type

The wordmark is set in **Archivo Expanded ExtraBold** (125% width, 800 weight). Secondary text is set in **JetBrains Mono**. Both fonts are available under the SIL Open Font License. The PNG assets contain rendered text only, so the fonts are not redistributed here.

## Rules

- Keep the star as the only accent colour, and never recolour the M.
- Leave clear space around the mark of at least the star's height.
- Don't rotate, outline, add effects to, or rearrange the star and the M.
- At 16 px, use `app-icon.svg`, which is tuned for small sizes.
