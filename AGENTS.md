# AGENTS.md

Instructions for coding agents working in this repository live in [`CLAUDE.md`](CLAUDE.md). Read it first, whichever agent you are: the project overview, the conventions (pull requests only, DCO sign-off, commit named paths only, publishing is the operator's, public by default) and the quality gates apply to every agent.

The harness conventions are in [`docs/harness/charter.md`](docs/harness/charter.md). The guard hooks under `.claude/hooks/` bind Claude Code sessions only; other agents follow the same rules by hand.
